Map

The chart is stored on the display's microSD card (FAT32). Uploading a chart set also sets the centre position below to the chart's centre. You can instead copy the builder's ais_map folder to the root of the card and restart the display.

Wi-Fi

The new network is tested before it's saved. If it fails, the display goes back to the previous network (or its setup access point).

Display firmware

Running…
Upload firmware/build/ais_display.bin to update the display. It restarts into the new firmware on trial: if that doesn't run for a minute (it crashes, or restarts), the display goes back to the current one by itself. A failed or interrupted upload changes nothing.

Wi-Fi chip firmware

Wi-Fi runs on a separate ESP32-C6 chip with its own firmware: currently version …. To update it, upload its firmware image (coprocessor/build/eh_cp_ota_coprocessor_ota.bin). The display restarts when it's done. If an update fails part way, the old firmware keeps running.

A plugged-in RTL-SDR Blog V3 dongle decodes AIS by itself, alongside the network feed.
"Best fixed gain" measures the noise at each gain step when the dongle starts (up to 25 s) and picks the highest gain that still leaves about 20 dB of headroom above the noise; it steps down by itself if a nearby transmitter overloads it. You can also set a gain yourself and compare packets per minute above. The RTL-SDR Blog V3 needs no frequency correction; cheaper dongles may (the decoder also corrects itself once it hears packets).
Recording saves the raw signal from the dongle on the USB-A port to the microSD card, for testing the AIS decoder on a PC: unsigned 8-bit I/Q (the same as rtl_sdr), centred on 162.000 MHz at 288 kS/s. One minute is about 35 MB.

Retransmit

Sends what the dongle decodes on to up to three places, as standard !AIVDM sentences: AIS sharing services (MarineTraffic, AIS Friends, aiscatcher.org each give your station an address and port when you register it), or chart software such as OpenCPN. The network feed isn't sent on. TCP connects to the address; UDP sends each sentence as a datagram.
